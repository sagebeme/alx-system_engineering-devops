0x03. Shell variables and expansions
=====================================

This project practices **shell variables and expansions**: using variables (`$VAR`), expansions (`${VAR}`, `$(cmd)`), and related syntax (aliases, exports).

## Learning Objectives

- Shell initialization files (`~/.bashrc`, `~/.profile`, `/etc/profile`)
- Local vs global (environment) variables and the `PATH` variable
- Arithmetic expansion, brace expansion and command substitution
- The `alias` command and `printf` number formatting
