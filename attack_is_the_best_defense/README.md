#Attack is the Best Defence

## About

Introductory **network security** exercises: packet sniffing and a dictionary attack, done in a controlled lab for learning purposes.

## Learning Objectives

- How network traffic can be captured and inspected
- How weak passwords are exposed by dictionary attacks and why strong passwords matter
