# What happens when you type www.google.com

## About

A write-up on **what happens when you type `https://www.google.com` in your browser and press Enter**, covering DNS, TCP/IP, firewalls, HTTPS/TLS, load balancers, web and application servers and databases.

## Learning Objectives

- The full request path from browser to server and back
- DNS lookup, TCP handshake, TLS and HTTP request/response
- The role of firewalls, load balancers, web/app servers and databases
